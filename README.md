# blueprint-cedar-specifications
Containing NIAID Blueprint-compatible metadata specifications (templates and example instances) built with CEDAR. 

The documents in this repository include metadata specifications created with the [CEDAR](https://cedar.metadatacenter.org) Workbench metadata system. They are compliant with the [NIAID Blueprint for Including Digital Objects in the NIAID Data Ecosystem](https://doi.org/10.5281/zenodo.17161561), or NIAID Blueprint, though they reflect the author's engineering judgment about which ontologies to support as controlled vocabularies, and what alternative formats to support for some of the fields.

Note: These artifacts have not been formally reviewed by or approved by NIAID representatives, and represent just one method of capturing metadata recommended by the NIAID Blueprint.

The repository includes all the formats (JSON Schema/LD, YAML, and CompactYAML) offered by CEDAR, in both a metadata template schema and an example metadata instance (based on metadata observed for a selected ImmPort study). The schema was obtained by filling out the CEDAR form for this template, using the observed ImmPort metadata.

Anyone with a CEDAR account can view the schema and instance artifacts, and all of the component fields and elements, in the CEDAR folder [NIAID Blueprint-Compliant Schema](https://cedar.metadatacenter.org/dashboard?folderId=https:%2F%2Frepo.metadatacenter.org%2Ffolders%2Fe9204d47-c9a0-4d61-83c5-ea27c7a36520).

These artifacts may also be viewed by anyone (no account needed) using CEDAR's OpenView service. Updated links may be found in the [OpenView](openview_links.md) Links file in this directory.
